## 概述

### 一、AIGC 的核心定义

**AIGC = 人类提供需求 + AI自动生成内容**

例如：

| 人类输入    | AI生成     |
|---------|----------|
| 写一篇科幻小说 | AI生成完整故事 |
| 输入提示词   | AI生成图片   |
| 上传角色图   | AI生成动画视频 |
| 描述音乐风格  | AI生成音乐   |

<chatmessage avatar="../assets/emoji/blzt.png" :avatarWidth="40">

所以本质是：**AI参与甚至主导内容创作。**

</chatmessage>

### 二、AIGC 可以生成哪些内容

<chatmessage avatar="../assets/emoji/bqb (4).png" :avatarWidth="40">
目前AIGC主要分为六大类：
</chatmessage>


| 类型   | 说明        | 常见工具                        |
|------|-----------|-----------------------------|
| 文本生成 | 写文章、脚本、小说 | ChatGPT                     |
| 图片生成 | AI绘画、设计图  | Midjourney、Stable Diffusion |
| 视频生成 | AI动画、短视频  | Runway、Pika、Seedance        |
| 音频生成 | 配音、音乐     | Suno、ElevenLabs             |
| 代码生成 | 自动写程序     | GitHub Copilot              |
| 3D内容 | 角色、场景模型   | Nvidia GET3D                |

---

### 三、AIGC 与传统内容生产的区别

| 模式       | 全称                             | 谁创作     | 特点       |
|----------|--------------------------------|---------|----------|
| **PGC**  | Professional Generated Content | 专业团队    | 成本高、质量高  |
| **UGC**  | User Generated Content         | 普通用户    | 内容多但质量参差 |
| **AIGC** | AI Generated Content           | AI + 人类 | 速度快、成本低  |


### 四、AIGC 工作流程（创作者常见流程）

<chatmessage avatar="../assets/emoji/bqb (4).png" :avatarWidth="40">
一个典型的AIGC制作流程：
</chatmessage>


```
创意
 ↓
脚本（AI生成）
 ↓
分镜设计
 ↓
AI生成图片
 ↓
AI生成视频
 ↓
剪辑 + 配音
 ↓
发布内容
```
